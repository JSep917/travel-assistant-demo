# 对话摘要

把较早的对话压缩成一份可继续使用的事实摘要，供后续规划直接读取。

## 保留

- 用户目标、已经确认的行程安排
- 出发地、目的地、日期、时间、预算
- 用户明确的偏好：城市、饮食、交通、兴趣
- 已经做出的选择、否定项、约束
- 尚未解决的问题
- 对后续对话仍然有用的事实

## 不要保留

- 寒暄、感谢、重复确认
- 工具调用过程、参数、原始 JSON
- 完整回答原文
- 已经失效的临时信息

## 输出要求

- 纯文本，不要 Markdown 表格
- 500 字以内
- 按“用户情况 / 已确认 / 待解决”组织
- 不要编造对话里没有的信息
- 如果旧摘要和新对话冲突，以新对话为准
